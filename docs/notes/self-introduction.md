# 面试自我介绍

## 口述稿

面试官您好，我叫徐天华，是南京大学信息管理学院图书情报专业的硕士研究生。本科毕业于北京大学信息管理系，专业是大数据管理与应用，同时在国家发展研究院修读了经济学双学位。

在专业学习方面，我主要学习了机器学习、深度学习等技术，并将其应用于信息抽取和知识图谱相关任务。同时，我也具备信息检索、数据分析和软件开发方面的知识基础。经济学双学位则让我进一步掌握了经济学和计量分析的相关方法。

在实习经历方面，我有过多段 AI 相关的实践经历。在衔远科技，我参与了模型训练数据构建、模型调优和推理部署；在南京鼐云，参与了数据智能体的开发；在天润融通，主要负责长文本 TTS 优化和音频质量检测。最近，我在华为参与 AI 测试 Agent 的开发，围绕测试脚本生成、任务执行和失败用例复测开展工作，同时对相关 Skill 和多阶段 Workflow 进行优化。

除了实习，我也结合自己感兴趣的方向开发了三个个人项目。

第一个是 Deep Research，一个多 Agent 深度研究系统，我主要关注任务编排、研究结果复核和中断恢复等问题。

第二个是 Agentic RAG，一个面向论文问答的系统，实现了混合检索、重排序和带引用的答案生成，并建立了检索与回答效果的评测流程。

第三个是 Forge，一个基于 LangChain 开发的终端 Coding Agent，支持代码读写和命令执行，我主要围绕会话管理、上下文压缩和子 Agent 协作进行了开发。

在学习和实践中，我比较注重目标拆解和过程验证，习惯把一个复杂问题分解成可执行的任务，并持续跟进结果。在团队协作中，我也比较重视需求沟通和实现细节。

未来，我希望继续深耕大模型和 Agent 应用开发，将自己的技术积累与实际业务场景结合起来。谢谢各位面试官。

## 时间安排

- 教育和学习背景约 40 秒。
- 四段实习约 40 秒，前三段各一句，华为稍多讲一点。
- 三个项目约 50 秒，项目之间稍作停顿，细节留给追问。
- 做事方式和求职方向约 20 秒。

面试官能看到简历，不必重复实习时间、完整职位名称和技术清单。实际时长按自己的语速朗读计时。

项目细节和追问准备见[项目深挖](./project-defense.md)。
