# 面试自我介绍

## 口述稿

面试官您好，我叫徐天华，是南京大学信息管理学院图书情报专业的硕士研究生。本科就读于北京大学信息管理系大数据管理与应用专业，同时在国家发展研究院修读了经济学双学位。

我的学习主要围绕机器学习和深度学习展开，用这些方法做信息抽取和知识图谱相关任务，也学习了信息检索、数据分析和软件开发。经济学双学位则补充了经济学和计量分析基础。

在实习中，我逐步把这些知识用到实际业务里：在衔远科技参与模型的数据构造、调优和推理部署；在南京鼐云参与数据智能体开发；在天润融通做长文本 TTS 优化和音频质量检测。最近一段是在华为，围绕 AI 测试 Agent 做脚本生成、任务执行和失败用例复测，并优化 Skill 和多阶段 Workflow。

围绕实践中接触到的问题，我也做了三个个人项目。

Deep Research 是多 Agent 深度研究系统，我重点处理任务编排、结果复核和中断恢复。

Agentic RAG 做论文问答，重点是混合检索、重排、带引用的回答，以及不同检索方案的评测。

Forge 则是基于 LangChain 的终端 Coding Agent，支持代码读写和命令执行，我围绕它做了会话管理、上下文压缩和子 Agent 协作。

在学习和做项目时，我习惯先明确目标、拆解问题，再持续跟进和验证结果；与团队协作时，也会注意沟通需求和实现细节。接下来，我希望继续做大模型和 Agent 应用，把技术能力用到具体业务里。

## 时间安排

- 教育和学习背景约 40 秒。
- 四段实习约 40 秒，前三段各一句，华为稍多讲一点。
- 三个项目约 50 秒，项目之间稍作停顿，细节留给追问。
- 做事方式和求职方向约 20 秒。

面试官能看到简历，不必重复实习时间、完整职位名称和技术清单。实际时长按自己的语速朗读计时。

项目细节和追问准备见[项目深挖](./project-defense.md)。
