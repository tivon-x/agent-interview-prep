# 面试自我介绍

## 口述稿

面试官您好，我叫徐天华，是南京大学信息管理学院图书情报专业的硕士研究生。本科就读于北京大学信息管理系大数据管理与应用专业，同时在国家发展研究院修读了经济学双学位。

从本科到研究生，我主要学习机器学习和深度学习，并用这些方法做信息抽取和知识图谱相关的任务，后来逐渐把重点放在大模型和 Agent 应用上。

为了把这些知识用到实际问题中，我先后做了四段实习。最早在衔远科技，参与模型的数据构造、调优和推理部署；在南京鼐云，参与数据智能体开发，把数据处理和分析任务组织成工具和工作流；在天润融通，主要做长文本 TTS 的连续性优化和音频质量检测。最近一段是在华为，做面向数据通信产品的 AI 测试 Agent，围绕测试脚本生成、自动执行和失败用例复测，优化 Skill、多阶段 Workflow 和上下文组织。

在这些实践的基础上，我也通过个人项目，进一步研究 Agent 里的检索、任务编排和运行控制。

Deep Research 是一个多 Agent 深度研究系统，通过不同 Agent 分工完成资料搜集、核验和报告生成，我重点处理的是任务编排、结果复核和中断恢复。

Agentic RAG 做的是论文问答。我实现了混合检索、重排和带引用的回答，也搭了固定数据集上的评测流程，用来比较不同检索方案的效果。

Forge 则是一个基于 LangChain 的终端 Coding Agent，支持代码读写、搜索和命令执行。我围绕它做了会话管理、上下文压缩和子 Agent 协作等工程实现，重点关注长任务执行过程中的状态和运行控制。

以上就是我的基本情况。

## 时间安排

- 教育和学习方向约 30 秒。
- 四段实习约 50 秒，前三段各一句，华为稍多讲一点。
- 三个项目约 70 秒，项目之间稍作停顿，细节留给追问。

面试官能看到简历，不必重复实习时间、完整职位名称和技术清单。实际时长按自己的语速朗读计时。
