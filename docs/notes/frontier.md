# 前沿技术补充

这里只记录可能改变面试回答的新模型、新协议和新工程实践。每条内容必须能回答“它解决了什么问题”和“与现有方案相比改变了什么”。

## 记录模板

### 名称与时间

- **来源**：论文、官方技术报告或项目仓库。
- **解决的问题**：一句话说明。
- **核心机制**：不超过五点。
- **与已有方案的区别**：明确比较对象。
- **工程影响**：成本、延迟、可靠性、部署或开发体验。
- **可能的面试问法**：列出 2–3 题。
- **30 秒回答**：先说结论，再说机制与边界。
