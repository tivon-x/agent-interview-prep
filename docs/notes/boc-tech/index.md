## 数据库与分布式系统

- 数据库索引的作用，以及项目中的索引使用。
- 数据库事务操作与 ACID 特性。
- MySQL 与 Oracle 的区别。
- Redis 的基础数据类型和适用场景。
- 分布式事务有哪些实现方式？

## Java、并发与开发

- Java 的 `int` 与 `Integer` 有什么区别，如何判断相等？
- Java 异常如何分类和处理？
- 什么情况下会出现内存泄漏或内存溢出？
- 如何理解并发机制、`synchronized` 和并发容器？
- 前后端接口规范如何制定？前端开发有哪些特点？
- 如何从技术角度改善软件的使用体验？手机银行等应用如何优化体验？

## 数据分析与人工智能

- 如何理解数据挖掘，分类有哪些应用场景？
- 缺失值如何处理？数据清洗通常包括哪些步骤？
- 特征选择与降维有哪些方法？
- ETL 的三个步骤是什么？数仓 ODS、DWD、DWS 层分别做什么？
- 大数据技术如何处理文本、图片等非结构化数据？
- 如何理解卷积神经网络的结构，以及模型准确率与实际应用之间的关系？预测错误时如何处理？
- Python 与 PyTorch 的基本用途和理解。

## 银行科技与应用

- 数据分析、人工智能、大数据和区块链可以如何应用于银行业务？
- 数字化银行有哪些应用、收益和风险？技术如何促进金融服务发展？
- 区块链适合什么场景？如何结合具体业务解释？
- 技术开发与风险防范有什么关系？
- 如何提高电子银行中后台的处理效率？
- 物联网架构与 5G 有哪些基本概念和应用？

原页面中的参考答案包含示例经历和未经核实的效果数字，不能作为个人经历使用；技术细节应结合站内基础资料和实际项目核对。
