# 五分钟模拟与考前速看

最后 20 分钟：三轮各 5 分钟，剩下 5 分钟回听最不顺的两题。先闭卷回答，再看对应章节。

## 第一轮：简历与岗位匹配

| 时间 | 面试官提问 | 回答主线 |
| --- | --- | --- |
| 0:00～0:45 | 请做一个 45 秒自我介绍，说明技术栈。 | 教育背景 → Python / LangGraph / FastAPI → 华为 → RAG |
| 0:45～1:40 | 你在华为具体做了什么？ | 测试 Agent → 脚本生成 → 业务动作封装 → 失败复测 |
| 1:40～2:30 | 有没有业务成果？ | 具体能力 → 减少重复编写和排查 → 怎样衡量效果 |
| 2:30～3:30 | 你提到了 Agent，具体有哪些实现方法？ | Workflow、工具循环、先规划再执行、多 Agent，再接自己的例子 |
| 3:30～4:30 | 为什么来银行，为什么选择招行？ | AI 与业务结合 → 数据和经济学基础 → 招行 AI 应用方向 |
| 4:30～5:00 | 你有什么问题想问？ | 选择下面的一道反问 |

## 第二轮：Agent、RAG 与数据集

| 时间 | 面试官提问 | 回答主线 |
| --- | --- | --- |
| 0:00～0:45 | 自我介绍。 | 保持同一版本 |
| 0:45～1:35 | 介绍你的论文问答项目。 | 文档导入 → 混合检索 → 重排 → 带引用回答 |
| 1:35～2:20 | 为什么用混合检索？ | BM25 匹配术语，向量匹配语义，重排筛选候选 |
| 2:20～3:20 | 数据集怎么做，效果怎么评？ | 固定 15 问 / 134 篇论文 → 四条方案 → 检索、回答、耗时 → 逐题比较 |
| 3:20～4:15 | 你怎么处理 Agent 出错和反复调用？ | 输入校验、错误反馈、有限重试、状态保存、停止条件 |
| 4:15～5:00 | 如果搬到银行，你会怎么做？ | 内部知识助手 → 权限和文档版本 → 小范围评测试用 |

## 第三轮：招行 AI 与基础题

| 时间 | 面试官提问 | 回答主线 |
| --- | --- | --- |
| 0:00～0:45 | 自我介绍，突出专业技能。 | Python + Agent / RAG + 华为 |

## 反问：只选一道

如果给反问时间，可以问：

> 想请问这个岗位入职初期，更多是围绕行内已有 AI 平台开发业务应用，还是需要同时参与知识库、工具和后端服务的建设？

或者：

> 想请问团队目前更希望新人优先补齐哪些业务知识，才能更快参与 AI 应用开发？

## 最后十分钟只看这一页

| 题目 | 记住这些词就能展开 |
| --- | --- |
| 我是谁 | 南大图情硕士；北大大数据管理与应用；经济学双学位；Python |
| 华为做什么 | 黑盒测试；脚本生成；业务动作封装；Workflow；失败复测 |
| 实习成果 | 可复用动作；脚本生成与执行；减少重复编写和排查 |
| Agent 是什么 | 围绕目标；选工具；执行；观察反馈；继续或停止 |
| Agent 怎么实现 | Workflow；ReAct 工具循环；Plan-and-Execute；多 Agent |
| RAG 怎么做 | PDF → 解析分块 → BM25 + FAISS → FlashRank → 带引用回答 |
| 数据集 | KITE；15 问；134 篇论文；四条 Pipeline；固定条件逐题比较 |
| 评测结果 | B0 约 4.27，B1 6.0；后续方案有逐题退步；保留 B1 |
| 为什么来 | AI 结合业务；技术与经济学基础；长期做应用 |
| 招行 AI | AI First；对客“小招”；对内“CRM 小助”等助手 |
| 有没有用过 | 目前没用过；了解方向；关注意图理解、知识检索、人工衔接 |
| 敏感数据 | 最小访问范围；公司允许环境；脱敏；权限；日志 |
| 银行应用设想 | 员工知识助手；条款与版本；权限检索；评测后试用 |
| Java | Python 主力；接触 Java 封装和接口定义；结合项目补齐 |
| SQL | JOIN、GROUP BY、HAVING、索引、事务、参数化查询 |
| Python 异常 | raise；try / except；finally；重新抛出 |
| 浅拷贝 | 新外层、共享内部引用；copy / 切片；deepcopy 递归复制 |
| 效率 | 先定位；减少重复工作；异步与并发；减少无效模型调用；验证质量 |

## 模拟结束后检查四件事

- 自我介绍有没有在 45 秒左右结束，并且说出了技术栈？
- 实习和项目有没有讲清“做什么、自己做了什么、解决什么问题”？
- 遇到追问，能不能用一个具体技术点展开，而不是连续报框架名？
- 银行匹配度有没有联系自己的经历，而不是只说平台好、工作稳定？

上场前再说一遍：**我以 Python 为主，做过 Agent 和 RAG，能围绕具体业务把模型、知识和工具接成应用。**
