## 基本概念与职责

数据库（DB）是按数据模型组织的数据集合；数据库管理系统（DBMS）是定义、存取和管理数据库的软件；数据库系统（DBS）包括数据库、DBMS、应用、硬件与人员；数据库管理员（DBA）负责部署、权限、监控、调优、备份和恢复。

DBMS 提供数据定义与查询、完整性约束、权限控制、事务与并发控制、持久化、备份与恢复。关系数据库以表和关系为主要模型；NoSQL 包括键值、文档、列族和图数据库，约束及一致性语义取决于产品；NewSQL 一般保留关系模型和 SQL，同时追求分布式扩展。

## 关系模型与键

表中的一行是**元组**，列是**属性**。超键能唯一标识一行；候选键是去掉任何属性后都不能再唯一标识的最小超键。主键是选定的候选键；其他候选键可称为备用键。候选键包含的属性为主属性，其余为非主属性。外键引用另一个表或本表中的候选键，用于约束引用关系。

例如选课表 `(student_id, course_id, score)` 中，若一个学生每门课只有一条记录，`(student_id, course_id)` 可作为组合候选键；学生 ID 可以引用学生表主键。ER 图用实体、属性、联系及其基数描述概念模型，例如一个学生可有多条选课记录。

## 范式与函数依赖

- **第一范式（1NF）**：属性值在关系模型中保持原子性，不能把一个字段用于多个独立值的重复组。
- **第二范式（2NF）**：满足 1NF，且每个非主属性完全依赖每个候选键，不依赖组合键的一部分。选课表若把学生姓名放在其中，姓名仅依赖学生 ID，宜拆到学生表。
- **第三范式（3NF）**：满足 2NF，并消除非主属性对候选键的传递依赖。比如学生表存 `department_id` 和部门名称，若部门名称依赖部门 ID，可拆出部门表。

规范化减少冗余与更新异常，但查询可能需要更多连接。按访问模式做反规范化时，要明确冗余字段如何同步以及允许的延迟。

## 主键、外键与约束

主键唯一标识行且不能为 NULL；外键限制引用值必须满足目标键的约束，通常可按数据库规则允许 NULL。数据库外键可防止孤儿记录，并可配置级联操作，但会带来写入检查、锁竞争、批量导入和跨服务治理成本。是否使用取决于一致性要求和系统架构；不用外键时，应用或其他机制要承担引用完整性责任。

## 存储过程

存储过程是保存在数据库端、可调用的 SQL 语句和控制逻辑，可减少客户端与数据库的往返并集中维护部分逻辑；也可能增加数据库负载、调试和版本管理难度，且不同数据库的语法和可移植性不同。

## DELETE、TRUNCATE 与 DROP

| 命令 | 作用 | 条件及影响 |
| --- | --- | --- |
| `DELETE FROM t WHERE ...` | 删除满足条件的行；无 `WHERE` 删除全部行 | 保留表结构；通常逐行执行相关删除逻辑；事务与触发器行为依数据库和引擎而定 |
| `TRUNCATE TABLE t` | 清空表数据 | 保留表结构；通常不能带 `WHERE`；锁、触发器、回滚和自增计数行为依数据库而定 |
| `DROP TABLE t` | 删除表对象及其数据 | 表结构也被移除；依赖对象和权限按 DBMS 规则处理 |

MySQL 的 `TRUNCATE TABLE` 属于 DDL，会隐式提交且不能像普通 InnoDB DML 一样回滚；不要将这一结论推广到所有数据库。具体权限与外键限制也需按数据库版本确认。

## SQL 分类

| 分类 | 常见语句 | 作用 |
| --- | --- | --- |
| DDL | `CREATE`、`ALTER`、`DROP`、`TRUNCATE` | 定义或改变数据库对象 |
| DML | `INSERT`、`UPDATE`、`DELETE` | 修改数据；部分分类也把查询纳入 DML |
| DQL | `SELECT` | 查询数据，常单列为一类 |
| TCL | `COMMIT`、`ROLLBACK`、`SAVEPOINT` | 管理事务 |
| DCL | `GRANT`、`REVOKE` | 授予或撤销权限 |

## 数据库设计流程

1. **需求分析**：明确业务对象、操作、约束、数据量和性能要求。
2. **概念设计**：用 ER 图梳理实体、属性、关系及基数。
3. **逻辑设计**：将概念模型转换成表、主键、外键和约束，检查范式。
4. **物理设计**：结合数据库和查询负载设计索引、数据类型、存储及分区。
5. **实施**：创建表和约束，导入数据，测试正确性与性能。
6. **运行维护**：监控、备份恢复演练、权限管理和持续调优。

选择字段类型时关注取值范围、精度、NULL 语义和兼容性；索引要针对实际查询验证，避免只按字段数量或经验规则机械添加。
