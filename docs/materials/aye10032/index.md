# 计算机基础笔记

这四套笔记由 Aye10032 整理，按原有目录阅读计算机网络、操作系统、计算机组成原理和数据结构。资料以 408 复习为背景，可按薄弱点补充基础知识，再结合面试问题复述原理与应用。

## 四科目录

1. [计算机网络](network/README.md)：体系结构、物理层、数据链路层、网络层、传输层与应用层。
2. [操作系统](os/README.md)：进程与调度、同步与互斥、内存、文件、磁盘与 I/O。
3. [计算机组成原理](organization/README.md)：数据表示与运算、存储器、指令、CPU、总线与 I/O。
4. [数据结构](data-structure/README.md)：线性表、栈和队列、串、树、图、查找与排序。
