# 7.1 计算机网络协议一览

## 7.1.1 数据链路层

### 一、流量传输与可靠控制

- **[停等协议](../di-san-zhang-shu-ju-lian-lu-ceng/3.4-liu-liang-kong-zhi-yu-ke-kao-chuan-shu-ji-zhi.md#_3-4-2-停止-等待协议)**：发一帧确认一帧
- **[GBN（后退N帧）协议](../di-san-zhang-shu-ju-lian-lu-ceng/3.4-liu-liang-kong-zhi-yu-ke-kao-chuan-shu-ji-zhi.md#_3-4-3-多帧滑动窗口——后退n帧协议-gbn)**：窗口内先往前发，直接确认最后一个帧
- **[SR（选择重传）协议](../di-san-zhang-shu-ju-lian-lu-ceng/3.4-liu-liang-kong-zhi-yu-ke-kao-chuan-shu-ji-zhi.md#_3-4-5-选择重传协议-sr)**
  - 接收方也有窗口
  - 单独确认每一帧
  - 乱序接受，齐了窗口自动走



### 二、介质访问控制

- **[ALOHA协议](../di-san-zhang-shu-ju-lian-lu-ceng/3.5-jie-zhi-fang-wen-kong-zhi.md#_1、aloha协议)**：冲突了就立刻重发
- **[CSMA协议](../di-san-zhang-shu-ju-lian-lu-ceng/3.5-jie-zhi-fang-wen-kong-zhi.md#_2、csma协议)**：先监听，根据信道状态决定是否发送
  - 1-坚持：有空直接发
  - 非坚持：随机时间
  - p-坚持：发送概率为p
- **[CSMA-CD协议](../di-san-zhang-shu-ju-lian-lu-ceng/3.5-jie-zhi-fang-wen-kong-zhi.md#_3、csma-cd协议)**：碰撞检测，重传时间为$r\cdot 2\tau$
- **[CSMA-CA协议](../di-san-zhang-shu-ju-lian-lu-ceng/3.5-jie-zhi-fang-wen-kong-zhi.md#_4、csma-ca协议)**：用于无线网，通过预约信道来实现



### 三、广域网

- **[PPP协议](../di-san-zhang-shu-ju-lian-lu-ceng/3.7-guang-yu-wang.md#_3-7-2-ppp协议)**：全双工、不可靠、面向字节
- **[HDLC协议](../di-san-zhang-shu-ju-lian-lu-ceng/3.7-guang-yu-wang.md#_3-7-3-hdlc协议)**：全双工、可靠、面向比特



## 7.1.2 网络层

### 一、IP协议

- [**ARP协议**](../di-si-zhang-wang-luo-ceng/4.2-ipv4.md#_1、arp-协议)：映射IP地址和MAC地址
- **[DHCP协议](../di-si-zhang-wang-luo-ceng/4.2-ipv4.md#_2、dhcp-协议)**：映射动态IP和主机
- **[ICMP协议](../di-si-zhang-wang-luo-ceng/4.2-ipv4.md#_3、icmp-协议)**：用于差错报告
- **[IGMP协议](../di-si-zhang-wang-luo-ceng/4.5-ip-zu-bo.md#_4-5-4-igmp协议与组播路由协议)**：用于管理IP组播组



### 二、路由协议

- **[RIP协议](../di-si-zhang-wang-luo-ceng/4.4-lu-you-suan-fa.md#_4-4-3-rip协议)**
  - 基于距离向量算法
  - 和相邻的路由器交换信息
  - UDP协议
- **[OSPF协议](../di-si-zhang-wang-luo-ceng/4.4-lu-you-suan-fa.md#_4-4-4-ospf协议)**
  - 基于Dijkstra算法
  - 向自治系统内洪范发送
  - IP协议
- **[BGP协议](../di-si-zhang-wang-luo-ceng/4.4-lu-you-suan-fa.md#_4-4-5-bgp协议)**
  - 外部协议，划分自治域
  - TCP协议
