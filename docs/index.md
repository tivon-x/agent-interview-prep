# AI / Agent 面试复习库

这不是资料收藏夹，而是面试前可以直接检索、口述和补漏的个人复习库。

## 当前主线

1. **AI 应用开发**：LLM 基础、推理、Agent、Workflow、Tool Calling、MCP、RAG、评测与可靠性。
2. **后端与数据平台**：Python 并发、网络、MySQL、Redis、消息队列、分布式、批流与数据治理。
3. **项目与简历**：Agentic RAG、Deep Research、Forge，以及实习经历的连续追问。
4. **字节专项**：数据平台 Agent 开发工程师岗位的 360 道题及逐题解析。

## 使用方法

每个知识点都按同一个闭环处理：

> 阅读 → 关闭资料口述 → 联系一个真实项目 → 回答一道题 → 记录不会的点

不要以“看完多少页”为进度。能在 60–90 秒内给出结论、依据、边界和改进方向，才算掌握。
