# 字节跳动数据平台 Agent 开发工程师面试题库

适用岗位：Agent 开发工程师，数据平台，2027 届校招，研发后端，职位 ID `A146899A`。

这份题库用于自测和模拟，不是官方题库。题目分为简历可核实部分、岗位能力延展和公开面经交叉主题。公开面经只能说明近期可能出现的考察方向，不能推断为本岗位固定流程或固定题目。

## 使用约定

- 标记：`难度` 为 基础、进阶、困难；`题型` 为 项目、原理、设计、故障、编码、行为；`关联` 写 JD 或简历事实。
- 回答顺序：结论，真实实现或设计依据，边界和失败处理。没有证据的线上指标、个人独立归属和生产结论不要补写。
- `追` 是递进追问，`要点` 只给自测锚点，不是标准答案。
- 简历项目的可讲范围：华为测试 Agent；Agentic RAG 的固定语料和冻结评测；Deep Research 的 Task Board、证据门禁、checkpoint；Forge 的 Harness、JSONL、工具边界。三者均不应说成已验证的生产多租户平台。

## 最高概率核心题

1. 90 秒介绍如何把华为测试 Agent、Agentic RAG、Deep Research 串成数据平台 Agent 工程主线？
2. Agent Loop、Workflow、Harness 分别解决什么，何时不需要 Agent？
3. 为什么 RAG 不能只看向量召回，如何做混合检索、重排和证据打包？
4. Agentic RAG 的 B0 到 B3 如何比较，为什么 B2/B3 没有晋级默认流程？
5. Deep Research 如何防止重复调度、旧结果覆盖和兄弟任务越权读取？
6. checkpoint 恢复时，如何处理运行中的任务和外部工具副作用？
7. Forge 为什么不自建第二套 Agent Loop，如何处理流式事件、取消和 session 持久化？
8. MCP 的 Host、Client、Server、Tool、Resource、Prompt 分别是什么，安全责任落在哪里？
9. 一个数据分析 Agent 从自然语言到 SQL、执行、解释和审计该如何设计？
10. 如何做 Agent 评测，区分检索指标、答案质量、工具成功率和线上业务指标？
11. 模型、工具或检索服务抖动时，哪些可以重试，哪些绝不能盲重试？
12. 多租户 To B Agent 的权限、数据隔离、审计、成本配额如何落地？
13. SSE 和 WebSocket 怎么选，用户取消发生在工具执行中如何收口？
14. 如何用元数据、血缘、指标口径降低 Text-to-SQL 幻觉？
15. 设计一个可恢复、可观测、可灰度的数据平台 Agent。

## 简历高风险追问

- 华为经历：只讲已确认的 AW 到 BAW 抽象、脚本转换、失败信息辅助复测和 Skill/Workflow 优化；没有统一评测集、提升比例或自主故障修复系统证据。
- Agentic RAG：冻结 KITE 结果属于特定 15 题、134 PDF、特定提交和 judge 协议，不等于真实业务准确率；B2/B3 未过 gate，默认仍为 B1。
- Deep Research：确定性 Readiness/Claim Verification 约束结构与证据，不证明网页事实绝对正确；外部评测曾受 Tavily 额度失败影响，不能说 live 质量已验收。
- Forge：路径检查不是 OS sandbox；HITL checkpoint、文件队列和安全能力都有进程/单用户边界；不把测试存在说成真实 provider 或多租户验证。
- AI 协作：可说自己负责需求拆解、方案选择、代码审查、测试验收和修正；不要把 AI 生成内容包装为独立完成的训练、线上交付或指标。
