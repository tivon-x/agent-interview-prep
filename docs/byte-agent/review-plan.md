# 面试前冲刺安排

## 总体分配

- AI / Agent 应用开发：40%
- 简历与项目深挖：35%
- 后端与数据平台：25%
- 晚上留给岗位投递
- 算法题按原计划独立复习

## 周六：AI 应用开发

重点覆盖 Agent 与 Workflow、Agent Loop、Tool Calling、MCP、Context、Memory、状态恢复、RAG 全链路、评测和可靠性。

完成标准：随机抽取 10 道相关题，至少 8 道能连续回答 60–90 秒，并能联系自己的项目。

## 周日：后端与数据平台

重点覆盖 Python 并发、HTTP/TCP/SSE、MySQL、Redis、消息队列、超时重试、幂等、批流处理、元数据、数据治理和 Text-to-SQL。

完成一道系统设计：面向内部与 To B 客户的数据分析 Agent 平台。

## 周一：项目与简历

- 30 秒和 90 秒自我介绍。
- Agentic RAG、Deep Research、Forge 各准备一套 3 分钟项目介绍。
- 逐条检查简历中的职责、指标、技术选择、失败案例和事实边界。
- 完成两轮模拟：项目＋Agent/RAG；后端＋系统设计＋行为面。

## 周二上午：收口

只复习补漏清单、自我介绍、三个项目、高频题和反问，不再学习新内容。
